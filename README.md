# منصة شؤون المواطنين

منصة عربية متجاوبة لتقديم طلبات المواطنين ومتابعتها ولوحة إدارة الموظفين.

## التشغيل
- Node.js 20+
- PostgreSQL
- متغيرات البيئة: DATABASE_URL وADMIN_USER وADMIN_PASSWORD وJWT_SECRET
- نفّذ npm install ثم npm start

## النشر على Render
ملف render.yaml يعرّف خدمة الويب وقاعدة PostgreSQL. أنشئ Blueprint من المستودع ثم راجع خطة الموارد قبل الموافقة. أدخل اسم مستخدم وكلمة مرور قوية لحساب الموظف في إعدادات الأسرار.

## المزايا
- استمارة مواطن مع تعهد وتوقيع بالاسم
- مرفق PDF/JPG/PNG بحد 4MB
- رقم متابعة وحالة معاملة
- لوحة موظفين محمية بتسجيل دخول
- تحديث حالة الطلب وإضافة ملاحظة وتنزيل المرفقات

## ملاحظات مهمة
- لم يتم تفعيل إرسال OTP/SMS؛ رقم الهاتف يُسجل كما يدخله المواطن.
- التوقيع الحالي إقرار بالاسم وليس توقيعاً رقمياً معتمداً أو بصمة حيوية.
- لا تضع كلمات المرور أو مفاتيح التوقيع في المستودع.
- قبل الاستخدام الرسمي، اختبر الصلاحيات والنسخ الاحتياطي وسياسة الاحتفاظ بالبيانات ومتطلبات الدائرة القانونية وتقنية المعلومات.
